Live RTSP Player  ·  how it works

From a camera stream to a browser tab

1

Camera URL

You paste an RTSP address (the link an IP camera gives out) and press Start Stream.

Done by you
→
2

Convert

The Flask server starts FFmpeg, which pulls the stream and re-encodes it into HLS: a playlist plus 2-second video chunks.

Done by FFmpeg
→
3

Serve

Flask serves the playlist and chunks. A background job deletes chunks older than 30 seconds.

Done by Flask
→
4

Play and edit

hls.js plays the stream in the page. You drag and resize text and logo boxes on top; each change is saved to MongoDB.

Done by React

Overlay positions are saved as percentages of the video frame, so they stay in place at any player size.
